# Ya Hala Market — Clean Complete Bundle

This is the only clean bundle to use for the Ya Hala Market Figma Make project.

Use this folder as the project root. It contains the complete current Ya Hala Market application copied from the integrated YaHalaMarket main repository:

- Public market, offers, offer details, plan flow, quote flow, and WhatsApp handoff.
- Lead capture, Supabase services, secure public submission, analytics, SEO, and migrations.
- Dashboard authentication, JetRoute-style dashboard shell, offers CMS, hotels, leads, quotes, reports, settings, team, and content management.
- Figma Make configuration, Vite configuration, package files, and QA documents.

Important: do not combine this bundle with BranchCast files or with any older phase folder. Copy this bundle as one complete project.
